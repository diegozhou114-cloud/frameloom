# Security Policy

## Supported Version Line

| Version line | Receives security reports |
| --- | --- |
| `0.1.x` | Yes |
| `< 0.1` | No |

Only the current minor line receives reports. Before 1.x, concurrent maintenance of older minor
lines is not promised.

## Reporting

Prefer GitHub Private Vulnerability Reporting. If private reporting is unavailable, email
diegozhou114@gmail.com. Do not disclose an unfixed vulnerability in a public Issue.

Reports receive intake and evaluation only; no response, remediation, patch, fix, or SLA is
promised. Any action depends on impact, reproducibility, and available capacity.
