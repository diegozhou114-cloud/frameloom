# Singleton Duplicate Initialization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every duplicate `SingletonDontDestroy<T>` component inert before any derived manager initialization runs.

**Architecture:** The generic base exposes a protected identity predicate backed only by its existing `_instance` field. Each current production `Awake` override calls the base, checks that predicate, and returns before manager-specific initialization when it is not the primary instance. This preserves manager independence and does not introduce a new service, registry, or cross-manager dependency.

**Tech Stack:** Unity 2022.3.62f3c1, C#, NUnit, Unity Test Framework PlayMode/EditMode, CodeGraph CLI, Git/Gitee.

## Global Constraints

- Scope is limited to the Unity client under `Assets/`; do not modify `Server/`.
- Do not implement YooAsset, AssetBundle, or Addressables behavior; those remain separate resource-management work.
- Use selected approach A. Approach B is recorded only as a discoverable, non-blocking follow-up comment.
- Keep the existing delayed `Destroy(gameObject)` behavior and public singleton API unchanged.
- Run Unity with exactly one editor process, without `-quit`; confirm zero Unity processes before and after every invocation.
- Treat Runtime tests as PlayMode tests.
- Before every push, run `git fetch gitee master` and stop for conflict resolution if the local branch is behind or diverged.

- [ ] **Step 1: Write behavior-first regression tests**

Create `Assets/Tests/Runtime/Core/SingletonDontDestroyInitializationTests.cs` with tests that compile against the current API and expose both real side effects:

```csharp
using System;
using NUnit.Framework;
using UnityEngine;
using ZWebGLFrameWork.Core;
using ZWebGLFrameWork.Data;
using ZWebGLFrameWork.Runtime.Tests.Support;
using ZWebGLFrameWork.UI;

namespace ZWebGLFrameWork.Runtime.Tests.Core
{
    public sealed class SingletonDontDestroyInitializationTests : RuntimeTestBase
    {
        [Test]
        public void DuplicateDataManager_DoesNotInitializeOrPublishDataReady()
        {
            int publishCount = 0;
            EventBus.Subscribe(DataManager.EventDataReady, () => publishCount++);

            DataManager primary =
                CreateOwnedObject("PrimaryDataManager").AddComponent<DataManager>();
            DataManager duplicate =
                CreateOwnedObject("DuplicateDataManager").AddComponent<DataManager>();

            Assert.That(DataManager.Instance, Is.SameAs(primary));
            Assert.That(publishCount, Is.EqualTo(1));
            Assert.That(duplicate.IsReady, Is.False);
        }

        [Test]
        public void DuplicateUIManager_DoesNotCreateUIRuntimeObjects()
        {
            UIManager primary =
                CreateOwnedObject("PrimaryUIManager").AddComponent<UIManager>();
            UIManager duplicate =
                CreateOwnedObject("DuplicateUIManager").AddComponent<UIManager>();

            Assert.That(UIManager.Instance, Is.SameAs(primary));
            Assert.That(primary.GetComponent<BuildingInfoController>(), Is.Not.Null);
            Assert.That(primary.GetComponentsInChildren<Canvas>(true),
                Has.Length.EqualTo(Enum.GetValues(typeof(UILayer)).Length));
            Assert.That(duplicate.GetComponent<BuildingInfoController>(), Is.Null);
            Assert.That(duplicate.transform.childCount, Is.Zero);
        }
    }
}
```
