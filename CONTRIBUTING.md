# Contributing

Use GitHub Issues for ordinary defects and feature discussions, and submit implementation changes
through pull requests. Security and conduct reports use the private channels in `SECURITY.md` and
`CODE_OF_CONDUCT.md`; those channels are not general support and carry no response or SLA promise.

## Contribution License

No CLA, DCO, Signed-off-by, bot, or signing service is required. Contributors retain copyright and,
by submitting a contribution, agree to publish project-owned contributions under the MIT license.
Contributors warrant that they have submission rights and that their contribution is non-infringing.

Quoted or adapted third-party material must disclose every third-party source, license, and change.
Content with unclear permission is prohibited. Vendored additions and updates require prior
maintainer approval and synchronized notices before submission.

## Pull Requests

Keep changes focused, describe the behavior and verification, and complete the repository pull
request checklist. Do not include generated Unity state, credentials, private evidence, or unrelated
formatting changes.
